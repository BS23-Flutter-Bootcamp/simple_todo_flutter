# 📝 To-Do App — Flutter + MVVM

A lightweight and clean To-Do application built using **Flutter**, following the **MVVM architecture**.  
This app allows users to **Create, Read, Update, and Delete (CRUD)** tasks with persistent storage using **Shared Preferences**.

## 🔹 Features

- Clean multi-page UI  
- Splash screen on startup  
- Offline data persistence  
- MVVM separation of concerns

> Perfect for managing your daily tasks with a smooth and minimal experience.
